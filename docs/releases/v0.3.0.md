## Agentic Hub 0.3.0

- **Automatic updates.** The app checks for signed releases, shows *Update available*, downloads with progress and restarts into the new version. Unsigned updates are never installed.
- **Setup in minutes.** A first-run wizard detects Git, Node.js, Claude Code, Codex, GitHub and Vercel, clones a repository from GitHub, and starts your first agent.
- **Code view.** File explorer, Monaco editor and an integrated terminal (⌘E, ⌘`). Files the agent edits are marked live, and you can see what it's doing and when it needs you.
- **Isolated worktrees.** Run each agent on its own branch without touching your checkout.
- **GitHub & Vercel.** Commit, push, open and review pull requests, merge, start an agent on an issue, deploy previews or production, and read build logs.
- **Safer approvals.** Every request is scored by risk. You can auto-approve low-risk actions; destructive commands, pushes, deploys, permission changes and secrets always ask. The old "auto approve everything" switch now maps to this policy.
