## Agentic Hub 0.3.1

- **Split work across agents.** In Multi mode, each agent now gets its own task (you can add the same agent twice), plus an optional shared goal. Every agent is told what the others are doing so they don't repeat each other's work. Each agent on the side-by-side board has its own follow-up box.
- **Updates install in the background.** The app checks every hour and when you switch back to it, downloads and installs updates on its own, and just asks you to restart. Failed installs show in the sidebar.
- **GitHub & Vercel side panel.** Pull requests, issues and deployments open in a panel on the right, next to your chat.
- Task boxes grow with longer tasks.
